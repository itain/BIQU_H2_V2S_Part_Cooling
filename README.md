<h1>A part cooling fan adaptor for the BIQU H2 extruder</h1>

Use with a 5015 blower fan.

The fan adapter is using 6 5x5x5 neodymium cube magnets. The magnetic holder piece is attached to the extruder with 2 M3 screws. The main part is attached to it with magnets.

Use M3 heat-insert nuts and 2 M3 screws to attach the blower fan to the main body.

The project was created with FreeCAD version 27.1.0dev. You may not be able to open it with release versions.
For convenience STL files are also included.

The main body may require supports for 3d-printing.

The 5x5 measuring stick is unly used to verify that the holes are clean and ready to accept the magnets. After printing it please check that it is indeed 5x5..
